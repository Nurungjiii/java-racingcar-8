# java-racingcar-precourse

## 구현 할 기능 목록

### 메시지
- 메시지로 프로그램 시작
  - 경주할 자동차 이름을 입력하세요.(이름은 쉼표(,) 기준으로 구분)
  - 시도할 횟수는 몇 회인가요?

### 객체

**Racing**

- [ ] 자동차 경주를 시작
- [ ] 라운드 지정 횟수만큼 진행

**Car**

- [x] 자동차를 생성
    - [x] 자동차 이름이 5자 이하인지 확인
- [ ] 자동차 전진 시도 (0-9 사이 무작위 값)
  - [ ] 무작위 값이 4 이상인 경우 전진
  - [ ] 무작위 값이 3 이하인 경우 정지

**Cars**

- [ ] 자동차의 이름을 쉼표(,)를 기준으로 구분
- [ ] 모든 자동차를 생성
- [ ] 모든 자동차의 전진을 시도
- [ ] 우승자 판별

**Input**

- [ ] 자동차 이름을 입력 받음
- [ ] 시도할 횟수를 입력 받음
- [ ] 사용자가 잘못된 값 입력한 경우 `IllegalArgumentException`을 발생시킨 후 종료

**Output**

- [ ] 차수별 실행 결과 출력
- [ ] 우승자 알리는 문구 출력
  - [ ] 단독 우승자 출력
  - [ ] 공동 우승자 출력
    - [ ] 공동 우승자의 경우 쉼표(,)를 이용하여 구분
